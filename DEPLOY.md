# Deployment

## GitHub Pages
1. Create a repository.
2. Upload the contents of this folder to the repository root.
3. In GitHub: Settings → Pages → deploy from the `main` branch.
4. Open the generated Pages URL.

## Vercel / Netlify
Upload the folder as a static project. No build command is needed.

## Hostinger
Upload the contents of this folder into `public_html`.

## Before going live
- Confirm the clinic phone number.
- Confirm current clinic timings.
- Confirm the Google Maps link.
- Replace/add the domain-specific OG image if desired.
