# Dr. Shaurya Skin Clinic — Website Bundle

A polished, responsive static website for Dr. Shaurya Rohatgi's Skin, Laser & Hair Transplant Centre in Andheri West, Mumbai.

## Included

- `index.html` — complete single-page website
- `style.css` — responsive visual system, animations, mobile layout
- `script.js` — navigation, reveal animations, image lightbox, appointment-to-WhatsApp flow
- `favicon.svg` and `assets/monogram.svg`
- `images/media/` — renamed clinic / doctor / procedure / event photography
- `images/reviews/` — renamed review screenshots supplied for the project
- `images/cases/prp-before-after.jpg` — cropped clinical image pair from the supplied PRP screenshot
- `images/cases/prp-source-screenshot.jpg` — original supplied PRP screenshot, retained for reference
- `ASSET_MAP.txt` — original upload IDs mapped to final filenames
- `SOURCES.md` — research references used for profile details and clinic location
- `DEPLOY.md` — quick deployment notes

## Content approach

The service catalogue was grouped from the Google Maps service screenshots supplied by the client. The screenshots themselves are not included in the public-facing gallery.

Patient feedback is reproduced from the supplied review screenshots. It is presented as individual patient feedback and not as a medical guarantee.

## Deployment

This is a static site. Upload the folder to GitHub Pages, Netlify, Vercel, Hostinger, or any standard static host.

No build step and no npm install are required.
